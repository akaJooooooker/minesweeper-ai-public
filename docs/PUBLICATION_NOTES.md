# Public release and evidence boundaries

Prepared 11 September 2026 from private revision 9a0420e. This is a separate curated repository, not publication of the private history or full archive.

PDF, DOCX and manuscript are the unchanged September 7 revision 2. “Standard blind test” in Table 1 names the historical report; it does not independently establish that the protocol preceded observed outcomes. This public release is not retroactive preregistration.

Original 6,000-pair rows and the exact historical solver snapshot are unavailable. The aggregate is preserved as historical evidence. Current-source reruns are new experiments. Historical 3BV/s and IOE are ratios of totals over each agent's own won games, not paired speed comparisons.

The newer 5,000 paired rows are complete: V44 2,189 wins, candidate 2,191; reference-only 6, candidate-only 8; exact McNemar p = 0.79052734375. Candidate not promoted. These first-zero, no-flag results differ from safe-only, flag/chord protocols.

Eight-worker execution had a Python SystemError and worker-pool termination. The historical manifest reflects initial execution and a resume; the report records four workers completing the remaining 882 pairs. The public subset omits the large traceback log with machine paths. Root cause remains unresolved; use four workers.

Packaging only changes bundled-resource and user-record locations. V44 weights and inference are unchanged. The actual binary check covers model loading, AI play, feedback, replay analysis and return to the live game. These are packaging checks, not a new efficacy or cross-machine experiment.
