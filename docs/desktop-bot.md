# V44 桌面版使用方式

目前支援 Windows、Minesweeper Online 的 Classic/HD 淺色與深色棋盤。預設是深色；自訂皮膚、動畫皮膚與瀏覽器色彩濾鏡尚未驗證。

## 啟動與校準

1. 雙擊專案根目錄的 `啟動桌面版.cmd`。
2. 在瀏覽器開啟棋盤，確定棋盤完整可見，而且開始後不要移動或縮放視窗。
3. 選擇尺寸、雷數與模式。高級是 16 列、30 欄、99 雷；無猜地獄是 20 列、30 欄、130 雷。
4. 按「點擊選取棋盤」。畫面變暗後，直接點左上第一格中心，再點右下最後一格中心；遮罩會攔住這兩次點擊，不會讓遊戲開格。
5. 先按「辨識一次」，檢查文字盤面是否和網頁相同。無猜盤應顯示綠色 X 的 `start=(列, 欄)`。
6. 用滑桿設定每步延遲，再按 F8 開始。任何時候按 F9 都會停止下一次點擊。

`standard` 允許最低風險猜測；`no_guess` 會先自動點網站指定的綠色 X，之後只走求解器證明安全的格；`multiplayer` 允許猜測、辨識不可點擊的 blackout 格，並在已揭露區域重新覆蓋時清除旗標狀態後繼續。

完成一局後會顯示實際動作數、耗時、3BV、3BV/s 與 IOE。只有在程式能由完整結束盤面確定所有雷的位置時，才會計算 3BV；否則顯示 `—`，不會用估值冒充。

## 安全邊界

- 校準所得的格子若明顯不是正方形，程式會要求重新點選。
- 連續三幀低信心、矛盾盤面或點擊後三幀完全沒變化時，程式會停止，避免失焦後點到棋盤外。
- 多人區域踩雷不當作整局結束；程式等待該區域重置並繼續。
- 目前請只在私人、自訂或匿名測試局使用，不要拿去影響排行榜或真人對戰。

## 匯出多人歷史對局 ID

先到 Minesweeper Online 的「My games」頁面，切到 Multiplayer／自訂對局的篩選結果，等表格載入後：

1. 按 F12，切到 Console。
2. 貼上 `scripts/export_mso_game_ids.js` 的完整內容並執行。
3. 右上角會出現 ID 清單；點文字框後按 Ctrl+A、Ctrl+C。
4. 把清單貼回對話即可。腳本只讀取目前篩選結果中的公開 game ID，不讀帳號密碼。

如果瀏覽器阻止貼上，依 Console 自己顯示的指示手動輸入允許貼上的文字；不要貼入來源不明的程式碼。
